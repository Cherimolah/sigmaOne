# sigmaOne

**sigmaOne** — это AI-движок для игры в **Дурак**.

Проект реализует интеллектуального игрового агента, использующего
нейросетевую оценку позиций и поиск по минимакс-дереву для выбора оптимальных ходов.

В текущей версии поддерживается:

- Формат: 24 карты
- Тип игры: переводной дурак
- Поиск: minimax
- Оценка позиций: обученная нейросеть

---

## Возможности

- AI-игрок для переводного дурака
- Нейросетевая оценка позиции
- Поиск лучшего хода через minimax
- REST API
- Возможность интеграции с фронтендом

---

## Производительность

Текущая версия показывает:

- ~75% winrate
- Тестирование против наивной стратегии:
  - Игрок собирает козыри

Это базовый ориентир производительности.

---

## Ограничения:
- Поддерживается только формат 24 карты, переводной дурак 1v1
- К сожалению, фронтенд сейчас на стадии разработки и не работает корректным образом

---

## Принцип работы
AI принимает решение следующим образом:
1. Генерируются возможные ходы
2. Строится minimax-дерево
3. Листья оцениваются нейросетью
4. Выбирается лучший ход

## Зависимости:
- Python 3.12+
- минимум (!!!) 32 гб оперативной памяти 
- довольно мощный процессор

## API

AI можно использовать через HTTP API.

### Получение лучшего хода

#### POST /predict

ID карт считаются от 0 до 23. В порядке от 9 до A (туз)  
Масти идут в таком порядке: ♣ (трефы), ♥ (червы), ♠ (пики), ♦ (буби)

Таким образом 6♣ - 0; 6♦ - 3; 7♣ - 4; J♥ - 17

Данные отправляются в теле запроса в формате JSON

| Название параметра   | Тип                                 | Комментарий                                                                                           |
|----------------------|-------------------------------------|-------------------------------------------------------------------------------------------------------|
| hand                 | List[int]                           | Карты в руке игрока                                                                                   |
| desk                 | Tuple[List[int], List[int \| None]] | Карты на столе. В первом списке карты подкинутые в атаку, во втором списке, карты подкинутые в защиту |
| known_cards          | List[int]                           | Карты, которые забрал противник                                                                       |
| count_opponent_cards | int                                 | Сколько карт в руке у оппонента                                                                       |
| bat                  | List[int]                           | Бито                                                                                                  |
| trump                | int                                 | Козырная карта                                                                                        |
| step                 | Enum                                | Тип хода. 1 - Атака игрока, 2 - защита игрока. Остальные не поддерживаются                            |
| opponent_take_mode   | bool                                | Берет ли соперник карты (сказал беру - игрок имеет право подкинуть карты в "догонку"                  |


##### Response  

В качестве ответа приходят SSE с различными данными в формате JSON

Для отображения прогресс-бара используется события со статусом "processing":
```json
{"status": "processing", "current_try": 1, "max_try": 6}
```

Когда ответ будет готов приходит последнее событие со статусом "finished":
```json
{"status": "finished", "action": {"type": 1, "card": 1}}
```

Список типов действий:  
1 - атака  
2 - перевод  
3 - защита  
4 - взятие  
5 - бито  
6 - отдать  
7 - приостановить атаку

## Установка

1. Склонировать репозиторий 
```shell
git clone https://github.com/Cherimolah/sigmaOne
```
2. Запустить виртуальное окружение
```shell
# Linux
python3 -m venv venv
source venv/bin/activate


# Windows
python -m venv venv
venv\Scripts\activate
```
3. Установить зависимости
```shell
pip install -r requirements.txt
```
4. Запуск
```shell
python main.py
```
